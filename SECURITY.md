# Security Policy

## Reporting a vulnerability

If you discover a security issue in this repository (the marketplace site, the
data files, or any of the bundled skills), please report it privately:

**Email:** security@skillhub.shop

Please do **not** file a public GitHub issue for security problems. We will
acknowledge receipt within 48 hours and aim to triage within 5 business days.

## Scope

- The `index.html` site and any client-side JavaScript
- `agents.json` and `skills.json` data files
- Any code or scripts published under this repository

## Out of scope

- The third-party skills themselves are maintained in their own repos. Please
  report vulnerabilities in a specific skill to that skill's maintainers.
